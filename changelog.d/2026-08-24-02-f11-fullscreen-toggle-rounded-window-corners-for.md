- **`F11` fullscreen toggle + rounded window corners for the Electron desktop wrapper** (this session, 2026-08-24, `FEATURE_BACKLOG.md` items 31/34, person-requested). Both scoped entirely to `desktop/main.js`: F11 is caught via a per-window `before-input-event` listener (no app menu exists to hang a menu accelerator on) and toggles `win.setFullScreen()`; rounded corners are requested explicitly via the `BrowserWindow` constructor's own `roundedCorners: true` option (Electron's default already — made explicit here). The "except when fullscreen" half of item 34 needed no code: a window that exactly fills the screen is squared off automatically by the OS compositor on both macOS and Windows, so it falls out for free once the window can go fullscreen at all (item 31). See "Desktop wrapper" → "Frameless window" above for the full writeup, including the per-platform caveats (Windows pre-11-Build-22000 stays square either way; Linux is desktop-environment/compositor-dependent, outside this app's control).

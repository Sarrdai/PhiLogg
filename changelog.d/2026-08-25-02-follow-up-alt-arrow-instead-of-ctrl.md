- **Follow-up: Alt+Arrow instead of Ctrl+Arrow for tree navigation, releasing the modifier closes a forced sidebar peek** (this session, 2026-08-25, two same-day person-requested follow-ups to the entry directly below). Ctrl+Arrow's tree-forwarding was renamed to **Alt+Arrow** — Ctrl+Arrow is standard OS/app behavior for jumps within a document (e.g. "next page") and needed to stay free for that; Alt+Enter (extraction) already used Alt, and Alt+Arrow doesn't collide with anything else in the app. Separately, releasing whichever modifier forced a sidebar peek open now closes it back up again — a new document-level `keyup` listener calls `clearSidebarForcedPeek()` on `"Control"`/`"Meta"`/`"Alt"`, safe unconditionally since a forced peek only ever exists because the sidebar WAS collapsed to begin with, so closing it on release just restores the pre-peek state (a peek opened by mouse hover isn't affected — `sidebarForcedPeek` is only ever true for a keyboard-forced one).

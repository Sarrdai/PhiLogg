- **Shortcut Manager in Settings** (this session, 2026-08-26, `FEATURE_BACKLOG.md` #48, retired: *"replaces the current Help button/shortcut guide with a proper manager (view and, if feasible, rebind app shortcuts) inside Settings"*). The header's `#btnShortcuts` help button now opens Settings directly on a new "Shortcuts" section instead of the old standalone `#shortcutsPanel` popup (removed outright, along with its CSS and open/close/outside-click wiring). The section has a rebindable-actions table for the 16 keyboard shortcuts that are single-purpose and unambiguous enough to safely rebind (new filter, rename/edit filter, close file, toggle sidebar/detail, undo/redo, bookmark, add note, focus tree, the three view switches, zoom in/out) — each is a `{ctrl,shift,alt,key}` combo with a default, overridable per-action and persisted as one JSON blob in `localStorage["philogg.shortcutBindings"]`, with conflict detection (can't assign a combo another rebindable action already uses) and a "Reset all to defaults" button. The rest of the app's shortcuts — mouse-driven ones (right-click/drag/double-click) and ones too context-dependent to safely rebind in one place (Ctrl+C/X/V, Del, Enter, arrows) — stay in a fixed reference list below the table, carried over unchanged from the old popup's content minus the now-covered entries.

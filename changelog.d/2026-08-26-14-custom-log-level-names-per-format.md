- **Custom log level names per format** (this session, 2026-08-26, follow-up to #47 after the person tried the fixed-five version and wanted their own vocabulary). A `LogFormat.levels` list is no longer restricted to `ALL_LEVELS`: it may contain arbitrary names (`NOTICE`, `CRITICAL`, `FATAL`, `VERBOSE`, …) alongside/instead of the five that own a theme color. `levelBucket(level, formatId)` became **format-aware** — it first tries an exact, case-insensitive match against the owning format's own list (that's what makes a custom name its own named bucket), then falls through the unchanged prefix cascade for the five known buckets, then `OTHER`; unrecognized free text deliberately still collapses into `OTHER` rather than inventing dynamic buckets, so counts and the level bar stay bounded by configuration. The `formatId` comes off the entry, already stamped at both parse sites by the earlier entry below. Every call site was threaded through (`entryComparator`, `getEntries`'s `"level"` branch, `getLevelCounts`, `applyLevelFilter`, both log-row renderers, the detail panel, the pair rows, the minimap), and `getLevelCounts()` keys off each entry's computed bucket rather than any fixed name list, so custom buckets are counted for free. Colors: a rotating categorical palette `--level-custom-1` … `--level-custom-6` per theme block (six distinct hues each, in the spirit of `COLUMN_PALETTE`, plus one `--level-custom-on`; `-soft` shades derived with `color-mix`), deliberately **not** added to `THEME_COLOR_KEYS` so previously-exported custom themes stay importable and simply inherit them. `customLevelSlot()` assigns a slot by the name's position among that format's *custom* names (wrapping after six), so a format always paints the same level the same color; `levelClass(level, formatId)` returns `lvl-custom-N`, with matching CSS alongside every existing `lvl-*` consumer (`.level-btn`/`.active`, `.col-bar`, `.level-badge`, `.log-row`/`:hover`, `.pair-row-bar`, `.minimap-lvl-*`). `levelSortRank()` places custom buckets between `TRACE` and `OTHER` by slot (`OTHER`'s rank moved to `5 + CUSTOM_LEVEL_SLOTS`), and the minimap now keeps the bucket *name* per column alongside the rank, since a rank no longer identifies a bucket by itself. Editor: the "Log levels" list keeps the five fixed checkbox rows and gains a name field + **Add** button (Enter works) below it; a custom row is always checked, reorders with the same ▲/▼, previews its palette color live, and carries a ✕ delete control instead of a checkbox-off (it isn't part of a fixed set to toggle back on). Rejected with an inline error: blank/whitespace-only input, the reserved `OTHER`, and case-insensitive duplicates of any row already listed. The "at least one level" save guard is unchanged, and existing formats (builtin default included) render and behave exactly as before.

- **3D scatter plot** (this session, 2026-08-28, person-requested — previously explicitly deferred, see `docs/extraction-and-plotting.md`'s old "lower priority" note). A new "3D" chart type in the Plot tab: X/Y/Z axis column selects plus an optional color-by column (blue→yellow→red gradient, same `plotColorScale` as 2D scatter). Hand-rolled — no 3D library in this codebase — a simple orthographic projection (`renderPlot3D()`/`project3dPoint()` in `philogg.html`) drawn on a new `<canvas id="plot3dCanvas">` sibling of `#plotSvg` (shown/hidden together depending on chart type). **Equal axis scale** is a select rather than a single checkbox — Off (each axis auto-fit), All equal (X=Y=Z), or any one pair equal with the third auto — since a 3D plot has three axes rather than two, unlike 2D's binary axis-equal toggle. **Interaction**: left-drag rotates (yaw/pitch), middle-click-drag or shift-drag pans, mouse wheel zooms, and clicking a point jumps to its log entry — same `jumpToFullLog` the 2D scatter's marks already use, plus a "Reset view" button. The 2D `#plotZoomBar` (zoom %, "Filter from plot view") is hidden for this chart type, since rotate/zoom/pan happen directly on the canvas instead. See "3D scatter" in `docs/extraction-and-plotting.md`. `tests/philogg.regression.test.js`: new **Group 125** — axis/color-by/axis-equal-mode controls, the per-axis scale math for all four axis-equal modes, rotate/zoom/pan mouse interaction, point-click-to-log-entry (and its empty-space/drag-suppression no-ops), and Reset view.

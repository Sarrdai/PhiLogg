- **Table/Plot now inherits upward through narrowing/context filters, stopping at link filters** (this session, 2026-09-04, person-requested). Previously `nodeHasExtractableWildcards(node)` — "does this node itself carry a `[value:...]`/`[*]` pattern" — was the sole gate for showing a node's Table/Plot views, so a timerange/idset/level/context/... filter created under an extraction-pattern node lost Table/Plot entirely, even though it conceptually should still show the (now further-filtered) extraction table/plot. New `findExtractionAncestor(node)` walks the parent chain for the nearest extraction-pattern ancestor, stopping (returning `null`) the moment a `"link"` filter is hit (its paired entries have a different shape, so nothing above it carries through) or the root is reached; `nodeIsExtractionView(node) = !!findExtractionAncestor(node)` is the boolean drop-in that now gates Table/Plot tab enablement, the Filtered-vs-extraction scroller pick, and remembered-view restoration, replacing `nodeHasExtractableWildcards` at those call sites (which itself is unchanged and still used directly for the tree's own `TBL` tag/icon and filter-editing UI, both about the node's *own* pattern specifically). `renderExtractTable` now resolves the pattern-bearing ancestor once and pulls `compileExtractPattern(...)`/`ignoredColumns` from it while still building rows from the *active* node's own (narrowed/extended) `getEntries(node.id)` — so a timerange filter under an extraction node shows the same columns, fewer rows. Pure live lookup, no new persisted field — see `docs/filters.md` → "Filter rules: the three movement classes, and Table/Plot upward-lookup inheritance" for the full model. `tests/philogg.regression.test.js`: **Group 173** (new) — a timerange filter under an extraction node inherits Table/Plot with the ancestor's pattern applied to the child's own narrowed entries; a filter under a link filter does not inherit past it; a plain narrowing chain with no extraction ancestor stays unaffected (regression baseline). **3374 passed, 0 failed** (3359 + 15).

- **Fixed: "Include subfolders" was a silent no-op for a watched folder under the desktop (Tauri) wrapper** (this session, 2026-09-09, person-reported). Root cause: `scanFolderHandle`'s recursion (`philogg.html`) only descends into an entry `handle.values()` yields with `kind === "directory"` — a real `FileSystemDirectoryHandle` yields those, but `nativeDirHandle`'s `values()` only ever yielded files from `philogg.listFolder` (backed by `commands.rs::list_folder`, a flat non-recursive `read_dir`), so under the wrapper there was never a directory entry to recurse into, regardless of the setting. Fix: new Tauri command `list_subfolders(path)` (`desktop/src-tauri/src/commands.rs`, registered in `main.rs`) returns a directory's immediate subdirectories, exposed as `philogg.listSubfolders` (`inject.js`); `nativeDirHandle.values()` (`philogg.html`) now also calls it and yields each result as a nested `nativeDirHandle` with `kind: "directory"`, so `scanFolderHandle`'s existing recursion (unchanged) works identically to the browser case. `tests/philogg.regression.test.js`: `nativeFolderBridge` (Group 145's mock wrapper) gained a matching `listSubfolders`; new **145f** watches a two-levels-deep native folder tree and asserts the setting actually recurses (and stops recursing when turned back off), including `relPath` for nested files. `docs/desktop.md` updated. **3787 passed, 0 failed** (`cd tests && npm test`).

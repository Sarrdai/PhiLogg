- **Follow-up: native "include subfolders" was slow, and "keep N newest" picked the wrong files across subfolders** (this session, 2026-09-09, person-reported from manual testing of the entry right below, ~30 files across several subfolders). Two bugs, one root cause: `scanFolderHandle`'s recency sort needs each file's mtime and fell back to an extra `getFile()` round trip per file when a handle didn't already carry one — for a native (Tauri) listing that fetches the file's real *content* over `philogg://local/…` for nothing, since the resulting `Blob` has no `lastModified` at all, so it bought nothing and cost an extra IPC + disk read per file on every rescan (the "few seconds"/"20-30 seconds" delays). With mtime absent, `sortFolderRecsByRecency` fell back to name (`relPath`) order — which groups by subfolder path first, so once subfolders were involved, "keep N newest" could pick stale files from whichever subfolder sorted last alphabetically instead of the actually-newest ones (exactly what was reported: 3 older files from one subfolder instead of the true 3 newest). Fix: `commands.rs::LocalFile` gained an `mtime: Option<u64>` field (`fs::metadata().modified()`, same units as JS `Date.now()`), read once per file during the same `read_dir` pass `list_folder` already does; `nativeDirHandle.values()` (`philogg.html`) attaches it to each yielded handle; `scanFolderHandle` uses `entryHandle.mtime` directly when present instead of calling `getFile()`. Also parallelized what was serial: `nativeDirHandle.values()` now calls `list_folder`/`list_subfolders` together (`Promise.all`) instead of one after the other, and `scanFolderHandle`'s own recursion now walks sibling subdirectories together instead of one at a time. `tests/philogg.regression.test.js`: `nativeFolderBridge` gained an `mtimes` param mirroring the new field; new **145g** — a top-level file that sorts last alphabetically but is chronologically oldest, against two subfolder files that are the real newest — asserts "keep 2 newest" picks the mtime-correct files, not the relPath-correct ones. `docs/desktop.md` updated. **3790 passed, 0 failed** (`cd tests && npm test`).

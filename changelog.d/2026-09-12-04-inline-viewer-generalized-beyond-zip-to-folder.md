- **Inline viewer: generalized beyond ZIP to folder-watch/direct-open, closable everywhere, JSON Pretty Print, fold-toggle bugfix** (this session, 2026-09-12, four person-reported/requested follow-ups after testing the previous session's rearchitecture). (1) **General file support**: a non-log inline-viewable file (`.txt`/`.json`/`.xml`/`.jpg`/`.png`/etc.) is no longer ZIP-only — `scanFolderHandle`'s folder-watch listing filter now also admits it (was hardcoded to `.log` only), each watched folder gets its own `inlineViewers` cache Map (mirroring `zip.inlineViewers`), and `loadFileDescriptors` (the direct-open/drag-drop funnel) now routes such a file to `openInlineViewer` instead of failing to parse it as a log — these get their own top-level closable tree row via the new `state.looseInlineViewers`. `openInlineViewer`'s viewer objects carry a generalized `ownerKind`/`ownerId`/`mapKey` instead of the old ZIP-only `zipId`; `viewerNavId` (generalized from `zipViewerNavId`) covers all three owner kinds for Alt+Up/Down nav. (2) **Bugfix: closing didn't actually work, in any context, including ZIP** — `.tree-del`'s hover-to-reveal CSS was scoped to `.tree-row`, but every inline-viewer entry row is `.folder-watch-file`/`.zip-source-file`, never `.tree-row`, so the close button was present in the DOM but never visible/clickable; added a matching `.folder-watch-file:hover .tree-del{opacity:1;}` rule, plus middle-click close (`auxclick`) to match a real log row's own affordance. (3) **JSON Pretty Print**: a new `#itvPrettyPrintBtn` toggle in the viewer header (visible only for `.json`) re-renders via `JSON.stringify(JSON.parse(text), null, 2)` without ever mutating the underlying source text; invalid JSON refuses with a toast instead of silently no-op-ing. (4) **Bugfix: the fold-toggle glyph added last session was invisible** — `.itv-fold-toggle`'s `left:-1.5em` measured from `.itv-line`'s own box edge, pushing it entirely outside `#inlineTextViewer`'s clipped content instead of into the gutter as intended; fixed with a dedicated non-negative slot. See `docs/ui-and-views.md` → "Inline text/image viewer" for the full writeup.

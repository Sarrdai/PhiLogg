- **Inline viewer: unified toolbar, fold-ellipsis position, and two bugfixes (viewer separation, image zoom precision)** (this session, 2026-09-13, four person-requested/reported follow-ups). (1) **Unified toolbar**: the image viewer's own floating overlay pill (`#imgViewerToolbar`) is gone, replaced with `#inlineViewerToolbar` — a real toolbar row using the same Controls | Settings grouping `#contextToolbar`/`#plotToolbar` already establish, shared by both the text and image sub-viewers (zoom controls in Controls, JSON Pretty Print in Settings), each group hiding itself when not applicable to the current file (`updateInlineViewerToolbar`). (2) **Fold-ellipsis position**: the `…` a collapsed fold shows now sits padded in to line up with the line-number column (`padding-left:1.3em` on `.itv-fold-ellipsis`) instead of flush-left under the fold-toggle arrow. (3) **Bugfix: the previously-open file's content stayed visible "behind" a newly opened one** — `#inlineTextViewer` never had its own `.hidden{display:none}` rule (every other `.hidden`-toggled element in this file does), so toggling that class did nothing visually; the `<pre>` kept rendering in normal flow underneath `#inlineImageViewer`'s absolutely-positioned box. (4) **Bugfix: drag-to-zoom on an image was imprecise** — the viewBox used to be built from the raw selection's own aspect ratio and left to the SVG's own default `preserveAspectRatio` to fit it, which silently added its own extra letterbox on top of a separate manual pixel-scale factor, breaking every pointer-to-data coordinate mapping whenever the domain's aspect didn't match the viewport's. Fixed by dropping the separate scale factor (viewBox now uses raw image-pixel units), setting `preserveAspectRatio="none"`, and adding `imgAspectFit` (expands the shorter side of a requested rect to match the viewport's aspect, centered, never cropping) — the drag-select handler now also clips the raw dragged rectangle to the image's own bounds before fitting it. See `docs/ui-and-views.md` → "Inline text/image viewer" for the full writeup. Regression coverage: GROUP 199 — 199ae/199af/199ag added, 199j/199ad updated for the new toolbar structure.

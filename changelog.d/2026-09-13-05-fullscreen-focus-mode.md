- **Fullscreen Focus Mode** (this session, 2026-09-13, implements FEATURE_BACKLOG.md #66, confirmed with the user; desktop-only in practice). A distraction-free mode toggled by `toggleFocusMode()`: the header (`#toolbar`) is removed outright (no hover reveal), the Files & Filters sidebar and the Entry Detail panel are force-collapsed to their edge-hover overlays, `#breadcrumbBar`/`#viewBar`/the timeline minimap stay visible, and the active log/extraction view takes the freed space. It **reuses the existing collapse + hover-peek mechanism** rather than inventing a new one: on enter it records the prior collapse states and `hoverExpandSidebar`/`hoverExpandDetail` flags, forces both panels collapsed and forces hover-reveal on regardless of the user's normal settings (the flags are toggled in memory only, never persisted); on exit it restores exactly what it captured. It's a body-level class flip (`body.focus-mode`), so it never rebuilds the tree (render-scope gotcha). **F11 no longer toggles plain OS maximize** — it now toggles Focus Mode, and is **rebindable in the Shortcut Manager** (new `toggleFocus` action, default F11). Real OS fullscreen is a **Tauri-only** capability, so the shortcut is only *handled* under the desktop wrapper (`window.philogg` present) — in the plain browser build F11 is not bound at all and the browser's own F11 keeps priority — and entering/leaving asks the wrapper to go fullscreen via a new `window.philogg.setFullscreen` bridge method → new Rust `window_set_fullscreen` command (`window.set_fullscreen`). `inject.js`'s old F11→`window_toggle_maximize` capture-listener is removed (the page owns the key now). Esc is a secondary exit, but only when no popup/menu/dialog is open (an overlay closes first — a single Esc never does both). `tests/philogg.regression.test.js` **Group 208** covers the page-side toggle: enter (header removed, sidebar+detail force-collapsed & hover forced, viewBar/minimap kept, `setFullscreen(true)` sent, prior state captured), exit (exact prior collapse+hover restored, `setFullscreen(false)`), a pre-collapsed sidebar honoured on exit, the F11 shortcut guarded to the desktop wrapper, and Esc's overlay-first secondary exit; Group 114's rebindable-action count updated 19→20. Desktop/Rust half is not jsdom-testable — verified by code review + `cd desktop && npm run build`. Full suite: **4203 passed, 0 failed**.

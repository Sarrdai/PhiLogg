- **Dialog UI consistency sweep + the `.pill-toggle` boolean control** (this session, 2026-09-14, implements FEATURE_BACKLOG.md #69, confirmed with the user). Applied `docs/ui-standard.md` across every popup/dialog, so it now documents the *current* state rather than a target. (1) **New `.pill-toggle` component** — the standard on/off control for a single boolean: a real `<button type="button" role="switch" aria-checked>` with an accent track + sliding knob (theme vars only, matching the `.panel-toggle-btn`/`.settings-switch` transition feel), replacing the native-checkbox `.settings-switch` used before. State lives in `aria-checked` (+ an `.on` class); read it with `pillGet(el)`, set it with `pillSet(el, on[, fireChange])` — **never** a `.checked` property (a button has none). One delegated document click handler toggles every pill, present or dynamically re-rendered (e.g. the plot controls), and a click on its adjacent `<label for=…>` is browser-forwarded to the button, so label clicks toggle it too; toggling dispatches a `change` event so existing change listeners keep working. **Converted** every listed single boolean: the filter popup's Regex/Case/Whole-word/NOT toggles, the link dialog's Exclusive/Order-enforce, CSV export's header/full-entry, the plot's Normalize/Equal-axis, and every `settings*`/`fwSettings*` boolean — all their `.checked` reads/writes rewritten to `pillGet`/`pillSet`. **Left as native checkboxes** (deliberately — they're set-selections, not on/off options): column visibility (`colToggle*`), the Plot Y-column picker (`plot-y-item`), and session-export per-file `session-include`/`session-embed`. (2) **Buttons** collapsed to the one-size `.btn-mini` (primary) + `.btn-mini-secondary` (secondary) pair — `.btn-mini-secondary` is now self-contained (same box as `.btn-mini`), and every dialog-footer Cancel/dismiss/alternative that had been a `.btn-mini-outline` is now `.btn-mini-secondary` (footer order stays secondary→primary); `.btn-mini-outline` is reserved for lightweight/additive actions (Reset, Add…, Change, Edit, Download template…, Clear). (3) **Hints** — trimmed every overlong `.settings-row-hint` to a single ≤~90-char line stating what the option does (multi-paragraph walls of caveats/history removed from the UI).

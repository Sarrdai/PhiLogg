- **Fix: the Value assertion dialog's Range/Target±Tolerance mode toggle didn't actually switch which fields were shown (this session, 2026-09-15, person-reported)**: `updateAssertModeUI()` toggled a `"hidden"` class on `#assertRangeFields`/`#assertTargetFields` correctly, but no CSS rule anywhere in the stylesheet targeted it — this project has no bare `.hidden{display:none}` rule, every one is scoped to its own selector, and this pair never got theirs — so both field groups stayed visible regardless of which mode button was active. Fixed with a scoped `#assertRangeFields.hidden, #assertTargetFields.hidden{display:none;}` rule. Regression-tested in Group 14 via `isVisible()` (real `getComputedStyle`, not just `classList.contains`) — confirmed to actually fail without the fix.

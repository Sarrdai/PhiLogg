- **feat: desktop — native, parallel log parsing in Rust (this session, 2026-09-24, person-requested: "Einlesen und Parsing nach Rust verlagern … gleiche Logik … möglichst viel Performance")**. Under the Tauri wrapper a file opened from disk (dialog, drop, folder watch, file association) is read and parsed by the new `philogg-logparse` crate (`desktop/src-tauri/logparse/`) on all cores via rayon, and streamed back to the page in 10,000-entry batches over a Tauri IPC channel (`parse_log_file` command, `window.philogg.parseLogFile` in `inject.js`). The file no longer passes through the webview as text (no `fetch`, `FileReader` or worker copy).
  - **Same logic, one definition**: the page still compiles each format; `nativeFormatSpec` (sharing the new `compileFormatRegex` with `compileOneFormat`) hands Rust the regex *source* this page would run. Rust translates JS-regex semantics exactly (`jsregex.rs`: ASCII `\d`/`\w`/`\b`, JS `\s`, JS `.`) and refuses what it can't mirror (lookaround, backreferences…), which makes the page fall back to its own parser for that file. `parseHeaderLine`, `applyFormatMatch`, `formatLocation`, `appendContinuationLine`, the timestamp parsers and `readAsText`'s BOM-sniffing decode are ported one function each.
  - **Timestamps** come back naive (`Date.UTC` of the fields); `makeNaiveTsLocalizer` converts them with the page's own engine, so DST and tz data are identical to the JS path.
  - **Falls back** (unchanged JS path) for meta-formats, unsupported regex constructs, a missing bridge and read errors; tailing appends, session restore, windowed loads and ZIP entries stay JS.
  - **Measured** (crate alone, 1M entries/154 MB, 4 cores): read ~0.25s + parse ~0.6s + JSON ~0.3s (a regex-mode format: parse ~1.3s), vs. ~3.7s for the page's own parse loop on one thread. What the page then spends turning the JSON batches into entries on its main thread is not in these numbers. Not yet run inside a real webview (see `desktop/README.md` → "Status").
  - **Tests**: new **Group 264** (spec, golden equivalence, adoption shape, rollback, the three load routes + fallbacks, DST localizer in five time zones) and a shared golden fixture `tests/fixtures/native-parse-golden.json`, which the crate's `cargo test` also checks (at slice sizes 1 B–1 MB), plus a brute-force `formatLocation` check. Full suite: **5509 passed, 0 failed**.

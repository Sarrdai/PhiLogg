- **feat: Export / Share — a ticket-oriented export: "Copy for ticket" snippet + full-view attachments (.log/.csv/.tsv/standalone HTML report)** (this session, 2026-09-25, FEATURE_BACKLOG.md #31 + #32 combined into one concept, requested as "an export/report concept especially useful for communicating findings via ticket systems like Jira"). Concept and current behavior: `docs/export.md`.
  - **Entry point**: one toolbar button, `#btnExport` (left of Settings), plus the rebindable shortcut `Ctrl+Shift+E` (`exportView`), opening `#exportDialog`. Nothing loaded → a "Nothing to export" toast.
  - **Copy for ticket** (the dialog's primary action): source file(s), time range, "x of y entries matched", the filter chain as numbered human-readable steps with per-step counts (`describeExportStep`; the level quick-filter becomes its own last step), the root file's bookmarks and notes, and an excerpt of the first N matching raw lines. Bounded for ticket fields: N adjustable (default 20, 0–500), each entry ≤ 1,000 chars, ≤ 25 bookmark/note lines, total ≤ 30,000 chars (under Jira's 32,767 limit); every cut is announced in the text.
  - **Flavors**: Markdown (Jira Cloud, GitHub, GitLab, Azure DevOps), Jira wiki (Server/Data Center: `h3.`, `{{…}}`, `{noformat}`), plain text — one segmented switch with a live preview, remembered in `philogg-export-format` (excerpt lines in `philogg-export-excerpt-lines`). Free text is escaped per flavor; the Markdown fence grows past any backtick run in the quoted lines.
  - **Attachments** (the full current view = the active node's result + level quick-filter, log order): `.log` raw lines, `.csv` (RFC 4180, the visible log columns incl. custom ones), `.tsv` (tab → space, line break → `\n`), and a standalone HTML report (chain, all bookmarks/notes, every matching entry with level colors and ★/notes inline; inline CSS only, no script, everything escaped). Built as chunked string parts (5,000 entries each) for one `Blob` — no DOM collection. Saved via `showSaveFilePicker` where available (Chromium, the Windows desktop build), else a download, the same path as the other file saves; a cancelled picker saves nothing.
  - **Privacy**: nothing leaves the machine except the explicit clipboard write or file save; only file names, never local paths.

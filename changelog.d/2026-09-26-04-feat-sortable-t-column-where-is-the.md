- **feat: sortable Δt column — "where is the most time lost" without a threshold (2026-09-26, follow-up to the Gap filter below)**. The Filtered view's Δt header is now sortable (first click largest first). Each row keeps its own chronological Δt under any column sort: `buildViewDeltaMap` captures it from the view list before sorting (only while a sort is active), and the row renderer reads it instead of the row above. Rows without a Δt sort last in both directions. On a gap node the map is the node's measured per-group gap, so `Gap ≥ 0 per Thread` + Δt sort ranks the longest per-thread pauses. `sortColumn: "delta"` is accepted by the session-cache/-import restore. Behavior change: Δt used to be dashed out under a column sort (GROUP 13 updated). Tests: new **GROUP 292**. Full suite: **6230 passed, 0 failed**.

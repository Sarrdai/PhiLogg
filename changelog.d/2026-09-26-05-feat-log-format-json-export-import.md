- **feat: log format JSON export/import (2026-09-26, person-requested)**. Each ordinary format in Settings → Log Formats gets an **Export** button (JSON with the definition and the globs of its filename rules). Import via the new **Import…** button there, or by dropping/opening the file anywhere in the app — `loadFileDescriptors` recognises the `philogg-log-format` marker in small `.json` files and opens `#logFormatImportDialog` instead of loading them. The dialog suggests the exported name and lets the person pick which filename patterns become rules (globs another rule already owns start unchecked). An import always creates a new format. See `docs/ui-and-views.md` → "Log format export/import (JSON)". Tests: new **GROUP 293**. Full suite: **6261 passed, 0 failed**. (The import side was reworked the same day by the unified import above — the Import… button and `#logFormatImportDialog` are gone, an import opens the format wizard.)

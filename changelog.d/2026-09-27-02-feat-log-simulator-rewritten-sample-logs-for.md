  - **Engine** `tools/log-sim/core.js` (new, UMD): seeded and time-zone independent — same seed + options = same bytes in CLI and page. 14 scenarios, one per feature area (stack traces, 2D/3D position, move/reached Link pairs with same-thread keys and slow/aborted cases, durations/clock times, sensor values with spikes, JSON-array spectra, embedded XML/JSON/.NET dumps, paths, GUID/IP/hex/URL, error bursts, idle gaps, extra levels, Unicode/long lines); 7 formats (builtin default, custom columns, bracket, JSON Lines, RFC 5424 syslog with numeric levels, mixed default+syslog for Meta formats, plain text). Every non-builtin format ships its PhiLogg format-definition export, written next to the output.
  - **Direct generation**: entries or approximate size per file, several files (`rotate` = one timeline, `parallel` = a service per file with optional clock skew), gzip, ZIP (own stored-method writer), CRLF.
  - **CLI** `tools/log-sim/cli.js` (new, no dependencies): `--list` prints formats and scenarios with the features they feed; batch output to stdout/file/folder/zip; `--follow` live mode with rotation. ~6 s for 100 MB.
  - **Screenshots** `tools/log-sim/screenshot.js` (new): headless Chromium with `philogg.html`, generated files and their formats loaded, optional page JS and theme.
  - **Page** `tools/log-simulator.html`: now loads the engine; format/scenario/seed/rate/start controls, "Generate" (download or chosen folder, progress), "Format definition", and the previous live writing (per-write open/close + write queue kept), whose content now follows the chosen format and scenarios.

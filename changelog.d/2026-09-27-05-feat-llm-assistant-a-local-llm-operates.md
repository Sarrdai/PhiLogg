- **feat: LLM assistant — a local LLM operates PhiLogg through a chat (desktop build) (2026-09-27, implements `docs/llm-assistant-plan.md` phases 1–6)**. See `docs/llm-assistant.md`.
  - **Phase 1 — tool registry**: `LLM_TOOLS`/`runLlmTool` in `philogg.html` — `get_overview`, `find_message_types` (message shapes with a per-placeholder value distribution and a ready-made extraction pattern), `create_filter`, `create_link`, `get_entries`, `get_value_stats`, `show_view` (incl. plot axes), `annotate` (bookmarks, notes that never overwrite the person's own). Results capped at ~1,500 tokens (`llmFitBudget`), argument problems come back as error text. Assistant-created nodes carry a ✦ in the tree (in-memory set, no node field). Tests: new **Group 302**.
  - **Phase 2 — Rust bridge**: new Tauri-free crate `desktop/src-tauri/llm` (`philogg-llm`): a small hand-written HTTP/1.1 + SSE client that only talks to `http://localhost|127.0.0.1|[::1]` (no DNS, no proxy, no redirects), Stop within ~200 ms via the socket read timeout; commands `llm_models`/`llm_chat`/`llm_cancel`, bridge `window.philogg.llmModels/llmChat/llmCancel`. Deviation from the plan: no `ureq` (see the plan's "Abweichungen"). Tests: `cargo test -p philogg-llm` (11, incl. a mock server streaming LM-Studio-shaped chunks).
  - **Phase 3 — agent loop and sessions (headless)**: `llmSend` runs a round (model ↔ tools until a text answer, the turn limit, Stop or an error), streamed text/tool-call deltas assembled page-side, one undo step per round (new `"batch"` undo action; `undo()`/`redo()` now go through `undoAction`/`redoAction`), "undo this round" also after further work (asks first if the person built on the round's nodes), no automatic rollback on Stop, older tool results compacted to one-liners, sessions in their own IndexedDB database, references stored as file key + ordinal / node definition and resolved per app run. Tests: new **Group 303** (scripted fake model).
  - **Phase 4 — chat window (first usable version)**: `desktop/chat.html`, a thin view that pulls complete session snapshots from the main window (a lost note heals on the next pull) and sends commands back; its own owned window (floats over PhiLogg, optional always-on-top, X hides, geometry remembered), toolbar button with an activity dot, streaming text, clickable/greyed node and entry references, Stop, "Undo this round" (asks first if you built on the round), "refers to … — not loaded" hint, Settings → Assistant (server URL, model list, temperature, turn limit, connection test). Rust: `llm_chat_window`, `llm_view_to_main`/`llm_main_to_view`, `chat.html` served and bundled. Backlog #70 removed. Tests: new **Group 304**.
  - **Phase 5 — several sessions**: new / switch / rename / delete chats (persisted, newest first, reference files as subtitle, each with its own model history, locked while a round runs); answer buttons for the model's questions ("- " option lines). Tests: new **Group 305**.
  - **Phase 6 — docking**: the chat as a side panel (`#llmDockPanel`, same `chat.html` in an `<iframe>`, `postMessage`), dock/undock between window and panel, toolbar button toggles the docked panel, state remembered (`philogg-llm-docked`). Tests: new **Group 306**.
  - **Tool defaults**: `find_message_types`/`create_filter` without an id work on the active node's whole file (found while making the screenshot: a model leaving the id out searched inside the selected thread filter and found nothing).
  - **Portable/installer**: `chat.html` is bundled (`tauri.conf.json` resources) and copied into the portable zip by both workflows.
  - **Screenshot**: new `docs/screenshots/10-assistant.png` (`docs/screenshots/generate.sh assistant`, scripted stand-in model, docked chat).
  - **Deviations from the plan**: listed in `docs/llm-assistant-plan.md` → "Abweichungen bei der Umsetzung". Phase 7 (acceptance test with LM Studio on Windows) is still open.
  - **Full suite**: **6750 passed, 0 failed** (Groups 302–306 also pass on the comment-stripped release copy); `cargo test -p philogg-llm` 11 passed; `npm run build` (desktop) passes.

- **test: the regression suite runs ~2.5x faster and its load-dependent flakes are gone (2026-09-30, person-requested)**
  - **Speed**: full suite 388s → 134s on one 4-core cloud container and 456s → 195s on a second, slower one, same groups and assertions (8333 passed; main itself failed 332e and 334c in that 456s run). Three harness changes, all in `tests/` (details in `tests/README.md` → "How it works"): new `tests/jsdom-fast-selectors.js` answers plain `[data-*]` selector lists from a per-document index instead of jsdom's selector engine (~45% of the suite's CPU time was `updateRowActionButtons`' ten document-wide queries per `render()`); `withApp` puts the app's stylesheet into its `<style>` after the parse instead of letting parse5 tokenize 280 KB of CSS per window; `run.js` shards claim groups one at a time through a `SHARD_CLAIMS` temp dir instead of a fixed modulo split, and cap each child's heap from the free memory (more shards than memory used to be OOM-killed).
  - **Exactness**: the fast path hands any query back to jsdom's engine when it meets an odd-shaped data-* attribute (uppercase, prefixed, namespaced), because jsdom's engine reads those differently from the spec. `JSDOM_SELECTORS=verify npm test` answers every eligible query both ways and throws on a difference (clean on the full suite); `JSDOM_SELECTORS=1` turns the fast path off.
  - **Flakes** (green alone, red only under full-suite load): 332d/332e — the app's `setInterval(tailTick)` / `setInterval(folderScanTick)` fired mid-assertion in any group outliving 1.5s; `withApp` now never schedules them (caught by function name), groups call the ticks themselves. 334c — counted pending jobs after a `sleep(10)` next to a 150ms dwell timer; now checks right after each synchronous step. 266b — the scroll renderer's `SCROLL_RENDER_BUDGET_MS` backoff kicked in whenever a loaded machine made one render slow; the group now hides its render time from `performance.now`. 343h lost a redundant `sleep(50)` after `T.bootRestore`.
  - **Tests**: new **Group 346** (fast path vs. jsdom's engine on the loaded page in five scopes, edge cases, index invalidation after 16 mutation kinds, stylesheet and polls in `withApp`); 266b, 332d/e, 334c, 343h updated.
